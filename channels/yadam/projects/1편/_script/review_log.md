# 리뷰 반영 대장 — 1편

게이트 규칙(`prompts/review-gates.md`): 회차마다 **무엇을 반영했는지 남긴다.** 안 남기면 같은 지적이 계속 돌아온다.
반영은 **우선순위 셋까지만.** 다 고치면 문장이 평평해진다(§5 밴드).

## 1회차 · G3 (1화 얼음광, 초반 3분) — 조건부 통과

| 지적 | 반영 |
|---|---|
| **1:41~2:33 무대사 52초** — 여인이 기어 오는 긴장 한복판에 얼음 저장법 설명이 들어온다 | 도입에서 공정 설명·아비 내력을 들어냈다. 원리는 4:47 아이 대사가 이미 묻고, 아비 이야기는 8:12에 그대로 또 있었다(중복) |
| 6~7번째 문장이 인물 신상이라 사건 대상이 32초 뒤에 나온다 | 신상을 뒤로 미루고 "강 건너 갈대밭 가에 검은 것이…"를 3번째 문장으로 당겼다 |
| 화자 표지가 없어 오디오로 누가 누군지 모른다 | "덕보가 물었습니다" / "노인이 혀를 찼어요" 표지를 붙였다 |
| 여인 대사가 여섯 번 연속 거절이라 다음이 예측된다 | 마지막 자리를 여인의 첫 질문으로 바꿨다 |

**★규칙 자체를 고친 건**: 기계 검사는 "대사 최장 공백 1.87분 통과"였다. 52초는 0.87분이라 안 걸린다.
도입은 아직 이야기에 붙지 않은 구간이라 같은 공백이 훨씬 길게 느껴진다 →
`check_retention.py`에 **H4(도입 3분 최장 공백 ≤0.7분)** 신설.

## 2회차 · G3 (2화 씨오쟁이, 초반 3분) — 조건부 통과

| 지적 | 반영 |
|---|---|
| **0~1분이 "씨오쟁이"라는 뜻 모를 말에 걸려 있다.** 뜻이 59초 뒤에야 나온다 | 첫 대사를 *"볍씨 내놔라! 네 집 씨오쟁이 내놓으란 말이다!"* 로 바꾸고, 뜻풀이를 **59초 → 5초**로 끌어올렸다 |
| 3분 내내 "걸린 것"이 없다 — 도둑으로 몰리면 무슨 일이 생기는지 아무도 말하지 않는다 | 만석 입으로 대가를 1분 안에 박았다: *"못 밝히면 관가로 끌고 간다. 곤장 스물이다."* |
| 같은 부인이 세 바퀴 돈다("남겼습니다." ×2) | 두 번째를 사실이 실린 대답으로 교체 — 왕복마다 정보가 하나씩 는다 |

기계 검사 여덟 항목이 전부 통과였는데도 사람이 읽으니 첫 1분이 통째로 비어 있었다.

## 2회차 · G4 (2화 씨오쟁이, 초고 전문) — 조건부 통과

**가장 아픈 지적은 내 설계 실수였다.** 축 표에는 "해결 주체 마을 ↔ 관아"로 갈라 놨는데,
리뷰어가 실제로 읽고 짚은 것은 이것이다:

> 두 편의 뼈대가 같다 — 귀한 것을 혼자 가진 사람 → 마을 위기 → 혼자 지킨 것을 나눠 줌 →
> 마을이 되갚음. **얼음이 볍씨로 바뀌었을 뿐이다.**

표만 갈라 놓고 정작 **클라이맥스의 모양**이 같았다. 2편에만 있는 축은
'가해자가 있고, 피해자가 끝내 용서하지 않은 채로 같은 마을에 산다'인데 30분에야 시작됐다.

| 지적 | 반영 |
|---|---|
| **6.4~9.5분 3분짜리 되감기** — 0.6분에 이미 들은 것을 되돌아간다 | **통째 삭제.** 살릴 값이 있던 "개가 안 짖었으면 동네 사람"만 분이 대사로 앞당겼다 |
| 7.5~8.3분 인물 내력을 회상으로 또 넣는다 | 삭제. 살릴 대사 하나("조용한 집에서 사람이 굶어 죽습니다")만 관아 가기 전 밤 장면으로 옮겼다 |
| 20~30분이 '분이가 옳았다'를 확인하는 장면의 연속 | 사이의 평평한 장면들을 걷어내 자백을 앞으로 당겼다. **2편 고유 축에 네 장면을 새로 넣었다** — 마을이 만석을 내보내자 할 때 분이가 거부 / 시어머니가 "그만 풀어라" 하고 분이가 거절 / 물 차례 회의에서 만석 몫을 넣자고 하는 자리 / 도랑을 사이에 두고 마주 서는 이듬해 봄 |
| 주제를 비유만 바꿔 다섯 번 말한다 | 아이 비유·"한 논이오"·결말 서술 두 문단 삭제 → 하나만 남겼다 |
| 마을이 도우러 오는 장면 4회 · 아이 문답 2회 · 노인 변호 2회 · 시어머니 빈 논 회고 3회 | 각각 절반으로 줄였다 |
| **E1 도량 장면이 여섯** — 현감의 종자 하사는 모양까지 주인공 것과 같다 | 종자 하사 삭제, 권농 임명만 남겼다 |
| **E3 매질 묘사** — 곤장 스무 대 + 들것 + 다리 저는 묘사 | **§6 수위 위반.** 형벌을 논 넷 환수로 끝내고 곤장을 통째로 지웠다. 다리 저는 묘사는 노동의 흔적으로 바꿨다 |
| E2 벌이 다섯 겹 — 착한 선택이 손해로만 돌아온다 | 비녀 전당포 장면을 걷어 두 겹으로 줄였다 |
| 자백 장면에 침묵 필러가 여섯 — 가장 중요한 장면인데 리듬이 죽는다 | 무동작 문장을 동작으로 바꾸고, 이 편의 무게중심을 여기서 세웠다 |
| 32.0분 장소 오류 — 논둑인데 "마당이 조용해졌어요" | 동작 문장으로 교체 |

**반영 안 한 것**: 관아 판결을 '열두 집이 아직 못 믿는다'로 끝내 불신을 25분까지 끌라는 제안(C4).
압박을 한 단 올리는 것은 맞지만, 이 채널은 §0에서 **불쾌한 각성 0건**을 요구한다.
누명이 25분까지 안 풀리면 자다 듣는 사람에게 남는 감정이 답답함이 된다. **규칙이 이긴다.**
다만 같은 지적이 다음 회차에 또 나오면 규칙 쪽을 의심하고 개정 제안으로 올린다.
